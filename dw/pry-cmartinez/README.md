# Repositorio - Desarrollo Web 

Este repositorio organiza el trabajo del curso **Desarrollo Web** por semanas. Cada carpeta de primer nivel corresponde a una actividad distinta:

| Carpeta | Contenido |
| :--- | :--- |
| **CircularGuajira/** | Actividad correspondiente a la **evaluación del primer parcial**. |
| **Nsemana/** (ej. `2semana/`, `6semana/`) | Ejercicios realizados en clase durante la semana N. |
| **motores/** | Documentación de la dockerización de los 4 motores de base de datos trabajados en el curso: **MySQL, PostgreSQL, Oracle y SQL Server (MSSQL)**. |
