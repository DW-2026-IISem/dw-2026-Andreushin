# CircularGuajira Express II · Frontend

Frontend Angular 22 (standalone, zoneless, signals) con PrimeNG 22 (tema Aura) y Tailwind CSS 4 para
**CircularGuajira**. Consume la API de `app-circularguajira-express-ii` en `http://localhost:4000/api`.

- Proceso de construcción por ISS: [docs/PROCESO.md](docs/PROCESO.md)

## Uso

```bash
npm ci
npm start          # http://localhost:4200
```

## Validaciones

```bash
npm run build      # ng build (producción)
npm test           # pruebas unitarias (Vitest)
```
